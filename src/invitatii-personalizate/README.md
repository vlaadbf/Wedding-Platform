Pune aici paginile HTML/CSS/JS sau componentele pentru invitatii personalizate.

Cand adaugi o pagina, trimite-mi numele folderului/fisierului si o integrez in platforma ca pagina publica de invitatie.

Datele disponibile din platforma pentru integrare:
- nunta: miri, data, ora, locatie, adresa, dress code, imagine invitatie, program
- invitat: nume, status, locuri, meniu ales, alergii, mesaj
- formular RSVP: confirmare/refuz, numar persoane, meniu, alergii, mesaj
